# Data and input preparation

wine_quality.csv combines UCI red and white wine tables with a wine_type column. See DATA.md for CC BY 4.0 attribution and acquisition.

Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009). Wine Quality. UCI Machine Learning Repository. https://doi.org/10.24432/C56S3T. CC BY 4.0: https://creativecommons.org/licenses/by/4.0/. Red and white tables are concatenated with an added wine_type column.
